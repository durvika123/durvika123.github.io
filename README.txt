# For Parth ♡

A cute interactive Boyfriend Day mini-site.

## Open it
Just double-click `index.html` in a browser.

## Customize it
- Main text: edit `index.html`
- Colors/animations: edit `style.css`
- Interactions/surprises: edit `script.js`

No server is required. It works as a static website.

## Hidden interactions
- Tap the big heart in the hero.
- Open the envelope.
- Fill the love meter to unlock the conclusion.
- Tap the polaroids for hidden notes.
- Press the final surprise button.
- Click the tiny “one more secret” link.
- Type `LOVE` on the keyboard for another secret.
